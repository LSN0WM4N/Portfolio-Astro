# Portfolio 

Second version of my personal portfolio. 
Using Astro instead NextJS, being it a better solution for static 
content and this kind of pages. 

This is not a template, I'm not aiming to create an easy way to add/modify 
the content of this page. In the end I don't need a one click solution 
to add a job entry, redeploying every time i change something is more 
than enough. 


If you find any typo, want to propose some change or make any kind of 
contribution you are free to do it with a pull request or 
[sending me an email](mailto:rodriguezrondafrancis@gmail.com).
