## Overview

ChatLite is a real-time chat application built to explore modern web technologies and WebSocket-based communication. It allows users to exchange messages instantly through a clean and responsive interface.

---

## Features

- Real-time messaging  
- Online users detection  
- Instant message updates  
- Responsive UI (mobile & desktop)  

---

## Tech Stack

- React + Tailwind  
- Node.js + Express   
- MySQL   
- Socket.io   

---

## Key Learnings

This project helped me understand how to:

- Build real-time systems using WebSockets  
- Synchronize client-server state  
- Structure full-stack applications  
- Optimize UI updates for performance
