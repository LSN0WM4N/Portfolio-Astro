## Overview

Conway's Game of Life is a classic cellular automaton simulation built entirely with native JavaScript and HTML, with no external frameworks. The project renders an interactive grid where cells evolve across generations following Conway's original rules: birth, survival, and death based on neighbor count.

---

## Features

- Interactive grid to place and remove live cells
- Customizable initial cell patterns
- Adjustable simulation speed
- Start, pause, and reset controls
- Fully browser-based with no dependencies

---

## Tech Stack

- HTML
- JavaScript (vanilla)
- Node.js (local dev server)

---

## Key Learnings

This project helped me understand how to:

- Implement cellular automaton logic using 2D grid state management
- Manipulate the DOM efficiently for real-time rendering
- Build interactive UIs without any frontend framework
