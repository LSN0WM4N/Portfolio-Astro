## Overview

A classic Tic-Tac-Toe game built as part of a project-based roadmap to learn React and practice TypeScript. The project focuses on managing game state with React hooks and building a clean, responsive UI using Tailwind CSS — keeping the logic simple while getting comfortable with a typed component-driven workflow.

---

## Features

- Two-player local gameplay
- Win and draw detection
- Game state management with React hooks
- Clean and responsive UI with Tailwind CSS

---

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

---

## Key Learnings

This project helped me understand how to:

- Apply TypeScript types and interfaces in a React project
- Manage component state with the `useState` hook
- Structure a small React application from scratch
- Build responsive UIs quickly with Tailwind CSS
