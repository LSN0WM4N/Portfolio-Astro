## Overview

DominoPlayer is a REST API built in Go that implements the complete logic of the domino game. It was developed as a solution for the ICPC Caribbean Finals 2023 challenge, where it achieved 3rd place. This was my first public repository and marked the beginning of my journey in software development outside the competitions.

---

## Features

- Full domino game logic exposed via REST API
- Game session and player turn management
- Move validation following official domino rules
- Docker containerization for portable deployment

---

## Tech Stack

- Go
- Docker
